Image Analysis 0.3.8 — автономная поставка Windows/Linux x86_64

В архиве находятся только итоговое приложение, три выбранные модели с их
лицензиями, шесть Docker-образов и системные установщики для Windows.
Сравнительных моделей, датасетов, экспериментальных скриптов и данных автора нет.
Модели: RF-DETR Small; Florence-2-base-ft; OPUS-MT TC Big EN→RU.
Модели с дополнительными файлами занимают около 1,34 ГБ. Все зависимости
Python/ML, Elasticsearch, MinIO, RabbitMQ и nginx уже находятся в образах.

WINDOWS
Целевая система — Windows 11 x64 на Intel/AMD, .NET Framework 4.8 или новее,
поддерживаемая приложенными Docker Desktop и WSL. ARM и Windows Server
этой поставкой не поддерживаются. Windows 10 не входит в проверенную цель.

1. Полностью распакуйте ZIP в локальную папку. Сохраните папку offline рядом
   с Image Analysis.exe: один EXE не содержит многогигабайтных зависимостей.
2. Откройте Image Analysis.exe, выберите CPU или NVIDIA, нажмите «Запустить».
3. При отсутствии Docker мастер использует локальный установщик. Если WSL
   отсутствует, используется приложенный MSI. Для повторной настройки WSL
   есть отдельная кнопка. Подтвердите системные запросы и условия Docker.
4. При запросе перезагрузки выполните её и снова откройте этот EXE.
5. Мастер скопирует модели, загрузит готовые Docker-образы и откроет браузер.

Интернет установке приложения не нужен; скачивания и сборки отключены.
Офлайн-EXE при отсутствии файлов поставки останавливается с ошибкой.
Аппаратную виртуализацию нужно включить в BIOS/UEFI. Для Windows с удалёнными
системными компонентами WSL может понадобиться установочный носитель той же
версии Windows: недостающие компоненты ОС архив приложения не заменяет.
Автоматической установки драйвера видеокарты нет. CPU не требует NVIDIA.
Для NVIDIA необходим совместимый заранее установленный драйвер CUDA 12.8
и GPU в Docker Desktop. Переход на CPU при ошибке GPU не происходит скрыто.

Файлы, настройки и модели устанавливаются в
%LOCALAPPDATA%\ImageAnalysis\app. Сервисы работают в Linux x86_64 контейнерах
Docker Desktop через WSL 2; отдельную Ubuntu вручную устанавливать не нужно.
Интерфейс — http://localhost:8080 в браузере Windows. Данные остаются в volumes
Docker проекта kurs4-app. «Остановить» сохраняет данные. EXE без подписи
издателя; возможно предупреждение SmartScreen. Защиту Windows не отключайте.

LINUX
Нужен Linux x86_64 с уже работающими локальными Docker Engine и Compose v2
с поддержкой !reset (2.24.4+), обычными sh/sha256sum и правами доступа к Docker.
Приложение распакуйте в папку с правом записи. Дополнительный Python на хосте,
pip/apt, скачивание пакетов и сборка образов для приложения не нужны.

Запуск из распакованной папки:
    sh start-linux.sh cpu
Только подготовить и проверить поставку, не запускать сервисы:
    sh start-linux.sh cpu check
Остановка с сохранением данных:
    sh start-linux.sh cpu stop

Режим cuda требует заранее настроенных NVIDIA-драйвера и NVIDIA Container
Toolkit на Linux. Для прямого Docker в WSL есть режим wsl-cuda.
Удалённый Docker daemon этой установкой не поддерживается.
Настройки и установленные модели будут в app внутри распакованной папки,
данные — в volumes локального Docker. Откройте http://localhost:8080.

МЕСТО И ПАМЯТЬ
Рекомендуется 16 ГБ RAM и около 50 ГБ свободного места с учётом ZIP,
распаковки, установки образов и копирования моделей. Запас под пользовательские
результаты нужен отдельно. Worker использует лимит RAM 8 ГБ для CPU либо 5 ГБ
для GPU; прочим сервисам тоже нужна память. При необходимости увеличьте лимит
Docker/WSL. Настоящий полный CPU-инференс пока не проверен.
Большой размер связан с PyTorch/CUDA и сервисами итогового приложения.
Сравнительные веса при установке не загружаются и в поставку не входят.

СОХРАННОСТЬ ДАННЫХ И ОБНОВЛЕНИЕ
Используется проект Docker kurs4-app. Перед переходом со старой установки
остановите её и перенесите прежний .secrets/app.env и веса в новую app-папку.
Пароли должны оставаться прежними для существующих MinIO/RabbitMQ volumes.
Не запускайте параллельно две установки. Не удаляйте Docker volumes.
Пароли и журналы не передавайте другим людям без проверки содержимого.
Для распространения передавайте исходный ZIP, а не установленную app-папку.
Проверка файлов: offline/manifest.json и контрольная сумма ZIP рядом с архивом.

По умолчанию S3 локальный. Свой S3 настраивается по app/OPERATIONS.md;
он требует доступности сервера, даже когда у компьютера нет интернета.
После успешного открытия браузера модели ещё прогреваются в worker.

Источники: app/README.md, app/OPERATIONS.md, app/CHANGELOG.md.
Docker Desktop: https://docs.docker.com/desktop/setup/install/windows-install/
WSL MSI: https://github.com/microsoft/WSL/releases/tag/3.0.3
Лицензии Python/моделей/контейнеров сохранены в их поставках.
