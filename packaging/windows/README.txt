Image Analysis 0.3.7 — Windows x64

КАК ЗАПУСТИТЬ
1. Распакуйте ZIP в обычную папку.
2. Откройте Image Analysis.exe двойным щелчком.
3. Выберите CPU или NVIDIA GPU и нажмите «Запустить».
4. Если Docker отсутствует, мастер скачает его официальный установщик,
   проверит цифровую подпись и откроет окно установки. Подтвердите запрос
   Windows и завершите установку Docker с Linux-контейнерами/WSL 2.
   Условия Docker принимает сам получатель в окне Docker.
5. Если Docker сообщает об отсутствии/устаревшей WSL, нажмите «Настроить WSL».
   При запросе Windows перезагрузите компьютер и снова откройте этот EXE.
6. Мастер скачает модели с проверкой SHA256, создаст случайные локальные
   пароли, соберёт контейнеры и откроет приложение в браузере.

Python и среда разработки получателю не нужны: Python уже встроен в EXE.
Первый запуск требует интернета: модели и Docker-образы большие, подготовка
может занять длительное время. Готовность API не означает окончания прогрева
моделей: после загрузки фотографии результат появится автоматически.

ТРЕБОВАНИЯ
Windows x64 с поддерживаемой Docker Desktop версией Windows, .NET Framework
4.8 (обычно входит в Windows), аппаратная виртуализация в BIOS/UEFI и WSL 2.
ARM, Windows Server и Windows-контейнеры этой поставкой не поддерживаются.
Рекомендуется 16 ГБ RAM и от 30 ГБ свободного диска сверх пользовательских
данных. Для CPU Docker/WSL требуется память для worker 8 ГБ и сервисов;
для GPU worker ограничен 5 ГБ RAM, остальные сервисы требуют память отдельно.
При недостатке памяти увеличьте лимит Docker/WSL в его настройках.
NVIDIA: нужен совместимый драйвер с поддержкой CUDA 12.8 и GPU в Docker.
Скрытого перехода с GPU на CPU нет. Настоящий CPU-инференс пока не проверен.

ПОВТОРНЫЙ ЗАПУСК И ОСТАНОВКА
Используйте тот же EXE. Скачанные модели повторно проверяются и используются.
«Остановить» останавливает сервисы, сохраняя данные. После успешного запуска
окно мастера можно закрыть; приложение продолжит работать в Docker.
Перезапуск через EXE использует установленные образы без пересборки и работает
без сети, если все образы и модели сохранились. Если образ отсутствует, мастер
соберёт его заново; для этого нужен интернет. Инструкция командного запуска
есть в README.md исходников.

НАСТРОЙКИ И ДАННЫЕ
Приложение распаковывается в %LOCALAPPDATA%\ImageAnalysis\app.
Пароли: app\.secrets\app.env внутри этой папки. Не публикуйте этот файл.
Модели: app\detection\models и app\annotation\models.
Журналы: %LOCALAPPDATA%\ImageAnalysis\logs; кнопка «Журнал» открывает текущий.
Данные Elasticsearch/MinIO/RabbitMQ хранятся в volumes Docker проекта kurs4-app.
Не удаляйте эти volumes при обычной остановке или обновлении.
Для своего S3 измените только пять S3-параметров в app\.secrets\app.env;
подробности — OPERATIONS.md в исходниках. По умолчанию S3 локальный.
Смена S3 автоматически не переносит старые изображения.
Не запускайте одновременно другие установки Image Analysis на этом Docker:
мастер использует общий проект kurs4-app. Старую установку сначала остановите;
для обновления из исходников сохраните и перенесите её .secrets/app.env и веса.

РАСПРОСТРАНЕНИЕ
Передавайте исходный ZIP выпуска. Он не содержит паролей, фотографий, данных
и весов автора. Не архивируйте установленную папку ImageAnalysis целиком.
app-source.zip содержит чистые исходники, документацию и скрипт пересборки.
SHA256SUMS.txt содержит контрольные суммы файлов поставки.
EXE не подписан коммерческим сертификатом: Windows SmartScreen может показать
предупреждение о неизвестном издателе. Не отключайте защиту Windows.

Проверена распаковка EXE и встроенный Python на Windows; логика настройки —
CPU/mock тестами. Полная установка на чистой Windows, системная установка
Docker/WSL и реальный инференс в этой проверке не выполнялись.
