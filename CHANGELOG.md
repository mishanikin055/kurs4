# История изменений

## 0.3.4 — 08.11.2026

- Документация Swagger использует локальные закреплённые ресурсы вместо CDN; добавлена инструкция запуска установленных контейнеров без интернета.

- Описания сцены и объектов показываются на русском: локальный Marian EN→RU работает в процессе Florence на CPU.
- Исходные ответы Florence сохранены без подмены; русский перевод находится в отдельном поле `russian_caption` в JSON и Elasticsearch. Старые результаты доступны без пересчёта.
- Загрузка закреплённых файлов переводчика и проверка весов входят в штатную установку; отдельный сервис и внешний API перевода не требуются.

## 0.3.3 — 07.11.2026

- Сохраняется общее изображение `detection.png` с bbox и COCO-подписями: PNG в S3, ссылка/размер/SHA256 в Elasticsearch. Исходник по-прежнему не сохраняется.
- Общая картинка доступна по API и входит в ZIP/выбранную папку вместе с JSON и вырезками. Старые результаты без неё остаются доступны без повторного инференса.
- Все PNG загружаются до условной публикации полного документа; при сбое загрузки общей картинки результат не становится готовым.
- Подготовлена чистая выгрузка приложения с шаблоном `.env`, без секретов, весов, данных и научных экспериментов.
- Удалены неиспользуемый импорт старых SQL-комплектов и прежние тесты PostgreSQL/worker; локальные пользовательские изменения таблиц/миграций сохранены.

## 0.3.2 — 07.11.2026

- Уточнены пошаговый запуск и подключение внешнего S3: настройки, доступ из Docker, права, проверка и переключение без автоматического переноса данных.
- Удалены локальные кэши и пустой каталог старого MCP; браузерные профили вынесены за пределы проекта. Кэши, MCP и неиспользуемые SQL-модули исключены из контекста Docker-сборки.
- Launcher автоматически выбирает S3 по endpoint: без внешнего адреса поднимает MinIO, с внешним адресом исключает его из сборки/запуска и отключает зависимость API/worker от локального контейнера.
- Проверяются обязательные настройки внешнего S3; ошибки не вызывают переключения на локальное хранилище. Пустой endpoint нормализуется в локальный адрес.
- При переключении прежний MinIO останавливается без удаления volume. Автоматического переноса вырезок нет; облачный провайдер ещё не проверен.

## 0.3.1 — 07.11.2026

- Подтверждён полный GPU-проход ранее загруженного изображения: результаты в Elasticsearch, 5 вырезок в S3, JSON/ZIP и удаление временного входа. Для текущей WSL потребовалось увеличить доступный лимит RAM/swap.

- Исправлена лишняя загрузка клиентов Elasticsearch/S3 в модельные процессы; освобождённые CPU-буферы загрузки моделей возвращаются системе раньше.
- При недостатке RAM/VRAM во время старта worker освобождает частично загруженные модели и ждёт 30 секунд, не забирая задания из очереди. Проверки запаса памяти сохранены.

## 0.3.0 — 07.11.2026

- Исправлен запуск worker в прямом WSL Docker: явная команда `wsl-cuda`, ранняя проверка NVIDIA runtime для `cuda`; уменьшен heap локального Elasticsearch до 512 МиБ.

- PostgreSQL заменён на Elasticsearch: аннотация сцены, классификация, детекция и ссылки на вырезки в одном документе.
- Отдельный локальный S3-контейнер MinIO хранит только вырезки; исходники не сохраняются, нормализованный вход удаляется после обработки.
- Просмотр использует локально выбранное изображение; ZIP и папка содержат JSON и вырезки.
- Launcher и Docker обновлены для Elasticsearch/S3; перенос старой БД не требуется.
- В AGENTS.md закреплён запрет лишних отчётов и проверок производительности без поручения.

## 0.2.0 — 07.11.2026

- Переносимый launcher: CPU, стандартный NVIDIA Docker, отдельный legacy WSL override; проверка весов и старой схемы до запуска worker.
- Florence: FP32 на CPU и FP16 на CUDA без преобразования целочисленных входов.
- Подготовка только двух закреплённых моделей отдельной командой без научных датасетов.
- Постоянное хранение фотографий, PNG, JSON и вырезок в PostgreSQL; отдельный каталог объектов и индексы для будущего SQL-поиска.
- Атомарная публикация готового комплекта, сохранение входа до подтверждённой отправки в RabbitMQ, выгрузка по запросу пользователя.
- Legacy-таблица сохранена; отдельный явный импорт прежних комплектов без повторного инференса.
- Документация продукта и запуска; прежние учебные документы/отчёты сохранены в archive/coursework.

Нагрузочные проверки на терабайтных данных и настоящий CPU/GPU инференс для этой версии не выполнены. Поиск по цвету/смыслу и видеомониторинг в выпуск не входят.

## До 0.2.0

История разработки сохранена в Git и archive/coursework. Старые Docker-теги v1/v2 отражали отдельные проверки и не были единой версией продукта.
