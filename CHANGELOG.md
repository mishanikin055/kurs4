# История изменений

## 0.3.0 — 07.11.2026

- PostgreSQL заменён на Elasticsearch: аннотация сцены, классификация, детекция и ссылки на вырезки в одном документе.
- Отдельный локальный S3-контейнер MinIO хранит только вырезки; исходники не сохраняются, нормализованный вход удаляется после обработки.
- Просмотр использует локально выбранное изображение; ZIP и папка содержат JSON и вырезки.
- Launcher и Docker обновлены для Elasticsearch/S3; перенос старой БД не требуется.
- В AGENTS.md закреплён запрет лишних отчётов и проверок производительности без поручения.

## 0.2.0 — 07.11.2026

- Переносимый launcher: CPU, стандартный NVIDIA Docker, отдельный legacy WSL override; проверка весов и старой схемы до запуска worker.
- Florence: FP32 на CPU и FP16 на CUDA без преобразования целочисленных входов.
- Подготовка только двух закреплённых моделей отдельной командой без научных датасетов.
- Постоянное хранение фотографий, PNG, JSON и вырезок в PostgreSQL; отдельный каталог объектов и индексы для будущего SQL-поиска.
- Атомарная публикация готового комплекта, сохранение входа до подтверждённой отправки в RabbitMQ, выгрузка по запросу пользователя.
- Legacy-таблица сохранена; отдельный явный импорт прежних комплектов без повторного инференса.
- Документация продукта и запуска; прежние учебные документы/отчёты сохранены в archive/coursework.

Нагрузочные проверки на терабайтных данных и настоящий CPU/GPU инференс для этой версии не выполнены. Поиск по цвету/смыслу и видеомониторинг в выпуск не входят.

## До 0.2.0

История разработки сохранена в Git и archive/coursework. Старые Docker-теги v1/v2 отражали отдельные проверки и не были единой версией продукта.
