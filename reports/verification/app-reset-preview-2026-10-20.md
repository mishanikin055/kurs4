# Чистая БД, просмотр результатов и Swagger — 20.10.2026

## Изменения

По явному запросу пользователя пересозданы пять контейнеров `kurs4-app` и volume
`kurs4-app_pgdata`. До остановки очередь `inference` была пуста. Перед сбросом
сохранён custom-format pg_dump в игнорируемой `.secrets/backups/`, проверено чтение
каталога архива. В старой `processed_images` было пять строк. Остальные volumes,
включая пользовательские изображения, не удалялись. Контейнеры чужих проектов
не затронуты; временные тестовые контейнеры удалены после проверки.

Новая миграция `d20f4a6b819c` удаляет `model_results`, `jobs`, `images` и оставляет
готовые результаты. Старые миграции сохранены. Активная ORM содержит только
`ProcessedImage`. После создания чистой рабочей БД проверены две таблицы:
`processed_images` (0 строк) и `alembic_version` (`d20f4a6b819c`). `alembic check`
не обнаружил расхождений с ORM.

Frontend по кнопке показывает PNG, исходный `raw_caption` и классы COCO/ImageNet,
сопоставленные по `object_id`. Текст модели выводится через `textContent`.
Polling отсутствует; до появления комплекта ручной запрос сообщает о неготовности.
В уведомлениях нет технических путей в volume. Swagger по `/api/docs` получает
схему через `/api/openapi.json`, Try it out использует сервер `/api`.

## Проверки

- CPU/mock: `pytest -q backend/tests` — 78 passed, 16 skipped.
- Изолированные PostgreSQL/RabbitMQ и отдельный Celery worker с mock-моделями:
  93 passed, 1 skipped. Проверены исторические миграции и сохранение готовой строки
  при удалении legacy-таблиц; тесты не использовали рабочую очередь.
- `ruff check --no-cache .`, `ruff format --check --no-cache .`, `git diff --check`
  и синтаксис JavaScript — без ошибок.
- Playwright с перехваченным API: ручной просмотр, исходный текст без HTML,
  сопоставление объектов, 404/503/пустой результат, отсутствие polling, сохранение
  четырёх файлов и ZIP, сброс при новой загрузке, мобильная ширина, Swagger/CSP.
- Настоящий Chromium открыл рабочий `/api/docs` с ресурсами jsDelivr;
  Try it out для `GET /api/health` вернул 200.
- Настоящие сохранённые файлы одного прежнего изображения отданы через nginx:
  PNG 640×366, два объекта, описание. Отправка изображения в этом браузерном
  сценарии подменена, поэтому новой задачи инференса не создавалось.
- Просмотрены desktop/mobile screenshots; горизонтальная прокрутка страницы
  отсутствует, таблица на телефоне прокручивается внутри своей области.
- После пересоздания worker все три настоящие модели прошли загрузку и прогрев,
  consumer подключился; это проверка старта, не новый полный model smoke.
- Во время завершающей проверки поступила новая пользовательская загрузка:
  worker завершил все три этапа за 0,796 с, в новой БД появилась одна готовая
  строка, очередь пуста. Агент эту задачу не публиковал. Это свидетельство одного
  рабочего сценария, а не измерение производительности или полный benchmark.

## Ограничения

Агент не запускал новый полный инференс изображения или научные сравнения. Настоящий
системный диалог выбора папки не проверялся (File System Access API подменён в тесте).
Swagger требует доступа браузера к jsDelivr. Дамп проверен чтением каталога;
полное восстановление старой рабочей БД из него не выполнялось.
