# Сравнительный анализ: COCO detector-crops

Все четыре готовых checkpoint завершили три повтора. Обучение, fine-tuning и LoRA не выполнялись. Качество — первый повтор; время и пиковые ресурсы — три повтора. Предсказания, включая top5 и softmax, совпали между повторами. Новые доверительные интервалы не рассчитывались.

500 заранее выбранных сцен COCO test, seed 42; 2296 вырезок, в условную точность включены 1054. Словарь: 287 ImageNet synsets → 56 категорий COCO. Поддерживаемые GT составляют 55.81% non-crowd объектов сцен. Неотображаемый ответ на поддерживаемом объекте считается ошибкой. Macro-F1 усредняется по 54 категориям с ненулевым GT-support.

Top-1/Top-5 оценивают общую категорию COCO, а не породу или подтип. Пять ImageNet-классов могут отображаться в одну COCO-категорию. Точность тонких подтипов по этим данным не измеряется.

Пороги score ≥ 0.5 и top1−top2 ≥ 0.1 диагностические, зафиксированы до оценки и не менялись после просмотра результатов. Они не калиброваны на неизвестные объекты; высокий softmax не подтверждает принадлежность словарю.

Гипотетическая замена использует категорию классификатора только при прохождении порогов. Эти значения оценивают возможное правило; в реальных сохранённых результатах effective_category_id и исходная метка детектора остаются неизменными. Условная matched accuracy исключает пропущенные, unsupported и crowd; supported recall учитывает пропуски. Ни одна из этих величин не заменяет COCO mAP полного детектора.

FP32, batch 1, 20 прогревов, 4 CPU threads, RTX 4050 Laptop 6 GiB / i5-12450H, WSL2 Linux Docker, PyTorch 2.7.1 CUDA 12.8 / torchvision 0.22.1. Строго один модельный дочерний процесс с общим inference.lock, runtime без сети и токена. CUDA синхронизируется на границах стадий. p50/p95 включают preprocessing/transfer, forward и postprocessing; чтение, crop, запись/fsync и холодная загрузка вынесены отдельно. RAM — peak RSS; VRAM — пики PyTorch, не полная память GPU.
