# Общие правила сравнений

## Активная структура с 11.10.2026

По [согласованному заданию](REFACTORING_TASK.md) каждое направление имеет четыре
содержательных файла моделей и один `common.py` в `scripts/<направление>/`.
Конкретная загрузка, native preprocessing и предсказание видны в файле модели.
Общий файл отвечает за данные, измерения, метрики, сохранение и таблицы.
Не добавлять runner/service/registry/plugin или новые обёртки.

Подготовка: `scripts/prepare.py <detection|classification|annotation>`.
Сеть разрешается только отдельным `--download`; источники/revisions/хеши
зафиксированы в прежних configs, manifests моделей и коде подготовки.
В runtime модели не скачивают файлы. Точные версии ML-зависимостей остаются
в трёх отдельных `requirements.in`/`requirements.lock.txt`.

## Протокол новых запусков

- Один проход каждой модели, batch 1, строго одна модель в RAM/GPU.
  Модельный дочерний процесс наследует `storage/locks/inference.lock` и
  завершается до оценки/следующей модели. Родитель не загружает веса.
- Одинаковые `--run NAME`, необязательный положительный `--limit N`,
  `--report-only` без весов/инференса. Прямые команды Docker Compose — [README](README.md).
- Детекция: прежние четыре checkpoint, COCO test4500, FP32, 20 прогревов,
  score floor 0.001/max исходных детекций 300; официальный COCO AP/AR
  с maxDets `[1,10,100]`; precision/recall score 0.5 и IoU 0.5.
  Sparse RF-DETR gaps исключаются без перенумерации; неизвестные ID — ошибка.
- Классификация: только ImageNet validation50k, FP32, 20 прогревов,
  прежние native transforms и порядок 1000 labels/synsets;
  Top-1, Top-5, Macro-F1 по всем 1000 классам и таблицы по классам.
- Аннотирование: COCO test500, FP16, один dev-прогрев, greedy/96 новых токенов,
  исходное RGB без выходов других моделей; `raw_caption` неизменен.
  CIDEr, BLEU-4, ROUGE-L, CHAIRs/CHAIRi; проверенный CHAIR с лицензиями сохраняется.
- Замеры CUDA синхронизированы; чтение, загрузка, прогрев и запись отделены
  от времени модели. p50/p95, скорость, cold load, peak RSS и PyTorch
  allocated/reserved записываются с единицами и ограничениями.

`reports/runs/<направление>/<run>/` изолирован от старых экспериментов.
Identity фиксирует набор, лимит, конфиг и исходники; несовместимое имя отклоняется.
Результат модели никогда не перезаписывается, resume нет; после прерывания
нужно новое имя сравнения. JSONL сохраняет предсказания и измерения изображений,
JSON — параметры/происхождение/статус. CSV/Markdown обновляются после модели
и содержат ровно четыре строки: отсутствующие/failed/OOM/incomplete не исчезают.
Сокращённые запуски не выдаются за полный результат.

## Исторические результаты и ограничения

Завершённые сравнения не повторять автоматически. Все сырые результаты,
таблицы, DOCX, manifests и source snapshots сохраняются; исходные конфиги
с прежним числом повторов не переписываются. Детекция/evaluation5000/crops
имели три повтора; основная таблица полного ImageNet использует одинаковые
первые два повтора (третий ResNet-50 сохранён отдельно); аннотаторы — один.
Новое правило одного прохода относится только к будущим запускам.

Новые доверительные интервалы/bootstrap запрещены для всех направлений;
старые интервалы сохраняются. Обучение/fine-tuning/LoRA, zero-shot CLIP/SigLIP2
и человеческая оценка исключены. Внешнего набора нет; это ограничение.
ИИ-разбор нельзя выдавать за независимую человеческую экспертизу.
Native разрешения, обучение авторов и возможные пересечения COCO с обучением
различаются; не делать вывод о чистом эффекте архитектуры или мировом рейтинге.
Доли/единицы метрик нельзя складывать в произвольный общий балл.

## Проверки и экспорт

По последнему уточнению пользователя от 11.10.2026 в текущем рефакторинге
модельные запуски и пересборка сравнительных таблиц прекращены. Приведённые
ниже GPU-проверки относятся к будущей отдельно запрошенной приёмке.

CPU/mock-тесты выполняются отдельно в соответствующих образах; реальные
офлайн короткие проверки всех 12 моделей и native parity детекторов/
классификаторов — отдельная приёмка. Проверять lock/остановку потомков,
ошибки/OOM, неполные данные, запрет перезаписи и смешивания параметров,
восстановление отчёта без весов. Полный benchmark для рефакторинга не нужен.
Baseline SHA-256 до переделки — `docs/refactoring-baseline.json`;
изменения инструкций ожидаемы, исторические результаты должны совпадать.

`scripts/export_tables.py --table CSV [--full]` выводит сохранённую таблицу
в консоль без моделей и зависимостей за пределами стандартной библиотеки.
`--table` можно повторить для нескольких сравнений. После модельного запуска
общий файл направления также выводит компактную таблицу четырёх участников.
По последнему указанию пользователя от 11.10.2026 Word-экспорт исключён
из переделки: существующие DOCX и manifests сохраняются, новые не создаются.
