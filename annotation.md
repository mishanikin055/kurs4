# Сравнительный анализ аннотаторов

Автоматическое сравнение test500 завершено 09.10.2026: четыре модели по
500 изображений, один проход без ошибок. Человеческая оценка исключена
пользователем; внешний набор и SPICE не использованы и указаны как ограничения.
Приложение и конвейер не реализованы.

С 11.10.2026 активный код — четыре содержательных скрипта моделей и один
`common.py` в `scripts/annotation/`; команды — [annotation/README.md](annotation/README.md).
Не создавать дополнительные CLI, runner, диспетчеры и платформенные слои.
Общие правила — [experiments.md](experiments.md), среда — [infrastructure.md](infrastructure.md).

Участники сохранены: BLIP base, Florence-2 base-ft, Qwen3-VL 2B Instruct,
SmolVLM2 500M Video Instruct. Это четыре закреплённых представителя, не
доказанный топ-4. Официальные revisions/источники/лицензии —
`annotation/configs/models.json` и [выбор моделей](docs/annotation_model_selection.md).
Веса остаются в `annotation/models/`, проверенные SHA — `models/manifest.json`.
Подготовка явно через `scripts/prepare.py`, runtime local-only и без сети.

Новые запуски: `--run NAME`, положительный `--limit N` для короткой проверки,
`--report-only` для восстановления таблиц без нейросетей. Один проход,
batch 1, FP16 без offload/квантования, greedy, 96 новых completion-токенов,
один прогрев на отдельном dev-изображении. Новые CI/bootstrap запрещены.
Старые configs/manifests и завершённые результаты не переписывать. Полные
прогоны ради рефакторинга не запускать.

Фиксированный test500 — локальный subset COCO val2017 из detector test4500;
это не официальный скрытый COCO test. Dev100 выбран из detector dev500,
seed 42, пересечений dev/test нет. Исходное изображение подаётся без overlay,
детекций и классификаций. Английская задача/промпты остаются прежними.
Qwen: 65536–262144 pixels, SDPA; SmolVLM — SDPA; BLIP/Florence — eager.
Florence использует проверенный закреплённый авторский код из локального
каталога, fast tokenizer и legacy tuple-cache compatibility; другие модели
не включают trust_remote_code. Собственного обучения нет.

Общий `storage/locks/inference.lock` должен удерживаться реальным модельным
дочерним процессом до выхода. Одновременно строго одна модель в RAM/GPU;
SIGTERM/INT координатора останавливает группу модельного процесса.
Новый формат — `reports/runs/annotation/NAME/{model_id}/{samples.jsonl,run.json}`,
общие `comparison.json`, `comparison.csv` и `comparison.md` в NAME.
В общей таблице всегда четыре участника и явные ошибки/OOM/incomplete/not_run/evaluation_failed.
Короткий запуск явно помечать, не выдавать за полный. Разные данные, параметры,
limit и версии исполняемых исходников под одним именем не смешивать.
Результат модели не перезаписывать; после прерывания новое имя, без resume.

Сохранять raw_caption без правки, completion IDs, точные prompts и параметры,
тайминги чтения/preprocess/generate/postprocess, p50/p95, tokens/s, images/s,
cold load, RSS и PyTorch allocated/reserved VRAM в bytes. Пики памяти включают
загрузку/прогрев, не включают память драйвера и других процессов. Cold load
измеряется после SHA-проверки и создания CUDA-контекста; файловый кэш ОС
не сбрасывается. Один проход не измеряет межпрогонную устойчивость.

[Проверенные метрики](annotation/evaluation/README.md): CIDEr, BLEU-4,
ROUGE-L, CHAIRs/CHAIRi, дополнительная объектная полнота. CHAIR использует
эталонные captions+instances и словарь авторов, не ответы детектора.
Не изменять проверенную CHAIR/Pattern реализацию и лицензии.
Не создавать человеческие баллы и не выдавать разбор ИИ за экспертизу.

500 изображений — практический бюджет внутри предложенных 500–1000,
shuffle seed 42 без стратификации; с историческим crop-набором совпадают
68 сцен. Test500 содержит 2500 references, 3623 instances включая crowd,
79/80 категорий без toaster; hair drier — 1 сцена, toothbrush — 2,
scissors — 3, bear — 4. Достаточность 500 и устойчивость ранжирования
не доказаны; редкие категории надёжно не оцениваются. Известное использование
COCO в обучении BLIP/SmolVLM ограничивает независимость обобщения.

CPU-тесты проверяют CHAIR lexical rules, реальные автоматические метрики,
raw_caption, частичные/дублирующиеся/переставленные samples, таблицы из четырёх
строк, identity и наследование lock/завершение process group. Реальные
короткие офлайн GPU-smoke всех четырёх checkpoint проверять отдельно.

## Итог автоматического сравнения

[Таблица](reports/comparisons/annotation-test500-v1/annotation.md),
[описание результатов](Описание%20результатов%20аннотирования.md),
[проверка](reports/verification/annotation-test500-v1.json).
Все 2000 неизменных captions сохранены; numeric report пересчитан из сырых
captions/timings, проверены decode parity и hashes источников/данных/весов.
Florence-2 base-ft имеет лучшие CIDEr/BLEU-4/ROUGE-L и минимальные CHAIRs/CHAIRi,
а также минимальную p50 в текущем протоколе. Qwen имеет наибольшую объектную
полноту, но более длинные ответы; низкий lexical CIDEr не доказывает отсутствие
смыслового качества. Один проход не измеряет межпрогонную устойчивость.
В актуальном объёме Florence-2 выбран для коротких английских описаний по измеренным показателям; независимая человеческая проверка не проводилась.

Сохранённое состояние и команды для будущих расширений — [docs/annotation_handoff.md](docs/annotation_handoff.md).
Готовые модели повторно не запускать ради отчёта; использовать сохранённый test500-v1.


[Дополнительный визуальный разбор ассистентом](reports/comparisons/annotation-test500-v1/qualitative_review.md)
охватывает шесть случайных изображений и 24 ответа. Это оценка ИИ, не слепая
человеческая экспертиза; human_scores и экспертные формы не заполнялись.


## Завершение по последнему указанию пользователя

Все три сравнительных анализа закрыты на фактически проверенных данных.
Человеческих оценок не будет по решению пользователя, поэтому поля состояния
этой оценки имеют значение `excluded_by_user`, а не `pending`.
[Общий итог](Итоги%20сравнительного%20анализа%20моделей.md),
[понятное описание работы](Как%20выполнялся%20сравнительный%20анализ.md).
Отсутствие внешних изображений и SPICE — ограничения выполненной оценки,
не незапущенные обязательные задачи текущего сравнения.


## Проверки упрощённой реализации 11.10.2026

20 CPU-тестов проходят, scoped Ruff check/format без замечаний. Все четыре
модели завершили реальный офлайн GPU-smoke по двум изображениям, FP16,
без замены checkpoint и без OOM. Все восемь raw_caption и последовательностей
completion IDs точно совпали с историческим нативным инференсом на этих сценах.
Report-only проверен отдельно без GPU. Полный инференс не повторялся.

CPU-пересчёт шести автоматических метрик на всех 2000 сохранённых captions
совпал с историческим CSV с допуском 1e-12; исходные captions неизменны.
[Проверка паритета](reports/runs/verification/annotation-parity.json),
[короткая таблица](reports/runs/annotation/refactor-smoke-20261011-v1/comparison.md).
Короткие результаты не заменяют завершённое основное сравнение test500-v1.
