# Пользовательский интерфейс

## Назначение и состояние

Интерфейс **Streamlit**: загрузка изображения, состояние обработки, исходное изображение и рамки, классификация объектов, raw/согласованный caption, предупреждения, история, поиск и экспорт. На 09.10.2026 UI приложения ещё не реализован.

Для задачи на интерфейс проверить существующий API и его схемы. Контракты и хранение — [backend.md](backend.md), смысл этапов и результатов — [pipeline.md](pipeline.md). Не предполагать наличие endpoints из плановой архитектуры. Начать с небольшого реального сценария, затем расширять интерфейс.

## Требования

- UI общается только с API по HTTP, без прямого доступа к БД и без весов/инференса.
- Rerun Streamlit не создаёт повторные задания: сохранить job_id/idempotency key, опрашивать статус и частичные результаты. Показывать очередь, текущий этап и конечные статусы/ошибки; поддержать отмену согласно API.
- Связать строки объектов с object_id и рамками. Показывать исходную метку детектора, отдельные top-k/synset классификатора, согласие/конфликт/отказ; разные scores не выдавать за общую уверенность.
- Раздельно показывать raw_caption, reconciled_caption и пользовательские ревизии с происхождением. Не скрывать пропуски моделей и частичные результаты.
- Поиск обращается к API и открытому провайдеру — [search.md](search.md). Показывать источники и время выдачи; недоступность поиска не уничтожает локальные результаты обработки.
- Экспортировать JSON и сохранённые изображения через API; изображения не помещать base64 в JSON результата.
- Streamlit-сервер использует http://api:8000; браузер пользователя — доступный адрес UI (предлагаемый localhost:8501). Не отправлять браузеру внутреннее DNS-имя контейнера как URL файла.

## Проверки

Повторный rerun/клик не создаёт дубль; исходный файл и overlay отображаются, кириллица читается, object_id соответствует таблице; ноль детекций, partial/failed/cancelled, перезапуск worker, недоступность API/поиска. Проверить сохранение ручной ревизии и экспорт. Compose/порты — [infrastructure.md](infrastructure.md). Сообщить отдельно о mock-проверках и реально пройденном пользовательском сценарии.
